# Payment data access notes

- `projects` are created by admin/staff and read by their customer.
- `installments`, `payments`, and `receipts` are written only by the trusted
  Express backend using Firebase Admin. Customers can read only documents whose
  `customerId` matches `users/{uid}.entityId`.
- A client may request a Razorpay order only through the backend with a Firebase
  ID token. The backend derives the amount and customer from the installment;
  it never accepts either as payment authority from the browser.
- Payment verification is idempotent by Razorpay payment ID and is committed in
  a Firestore transaction together with the installment and project aggregate.
